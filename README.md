# Smart-Load-Cell-Based-Food-Dispensing-Monitor-using-PIC16F877A-and-HX711-24-bit-ADC-
A custom PCB for precise food weight measurement, using a PIC16F877A and a 24-bit HX711 ADC to read load cell data. Assembly firmware handles data acquisition, and an on-board ICSP header (J1) allows easy programming and calibration. Includes fabrication files, documentation, and firmware (.asm and .HEX).
